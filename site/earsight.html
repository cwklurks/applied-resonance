How the result was produced.

The comparison uses the published DCASE 2020 Task 2 development baseline for the same MIMII machine types. It is a benchmark result, not evidence of field deployment.

Dataset and split

  • MIMII 0 dB fan and pump data
  • 5,893 normal training clips
  • 3,862 held-out normal and abnormal test clips
  • Scorers fit on normal clips only, per machine ID

Representation and scoring

  • PANNs CNN14 16 kHz, 2,048-dimensional embeddings
  • Cosine k-nearest-neighbour primary scorer
  • Ledoit-Wolf Mahalanobis secondary scorer
  • Seed 1337; AUC and pAUC matched to three decimals across two runs

The null result ships too.

A separate fan/pump classifier reached 1.000 training accuracy but only 0.577 validation accuracy on a held-out machine-ID split.

The model learned hardware-specific spectral signatures that did not generalize. That does not invalidate the per-ID anomaly scorers above, but it is a real limitation and remains in the report rather than being edited away.

The glasses are the demo. The box is the pilot.

EarSight began as a smart-glasses interface for field technicians. The interface remains useful for demonstrating live scoring, but the fall pilot is intentionally simpler: one hybrid sensor box per machine, alerts routed by phone, and a weekly report a shop owner can understand.
